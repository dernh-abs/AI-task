# 权限矩阵

MVP 默认策略：项目成员可读取项目内任务；只有拥有对应职责的人可以变更关键状态。非项目成员默认不可见。

| 操作 | CEO/团队管理员 | 项目负责人 | 任务负责人 | 协作者 | 验收人 | 普通项目成员 | AI |
|---|---:|---:|---:|---:|---:|---:|---:|
| 查看授权项目 | 是 | 是 | 是 | 是 | 是 | 是 | 继承发起人 |
| 创建项目 | 是 | 可配置 | 否 | 否 | 否 | 否 | 否 |
| 编辑项目/阶段 | 是 | 是 | 否 | 否 | 否 | 否 | 否 |
| 创建任务 | 是 | 是 | 是 | 可配置 | 可配置 | 可配置 | 仅候选 |
| 分配负责人 | 是 | 是 | 申请 | 否 | 否 | 否 | 否 |
| 接收任务 | 否 | 仅本人任务 | 仅本人 | 否 | 否 | 否 | 否 |
| 更新执行状态 | 是 | 是 | 是 | 否 | 否 | 否 | 仅建议/运行态 |
| 提交个人产出 | 是 | 是 | 是 | 是 | 可配置 | 否 | 运行输出 |
| 提交整体结果 | 是 | 是 | 是 | 否 | 否 | 否 | 否 |
| 验收通过/退回 | 是 | 仅授权时 | 否 | 否 | 是 | 否 | 否 |
| 转等待外部 | 是 | 是 | 是 | 否 | 否 | 否 | 仅建议 |
| 查看审计 | 是 | 本项目 | 本任务 | 本任务只读 | 本任务 | 否 | 否 |

所有服务端权限检查使用统一依赖或策略模块；前端隐藏按钮仅改善体验，不能作为安全边界。
