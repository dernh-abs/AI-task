- `task-state-machine.md`：任务状态转移、权限守卫和副作用
- `permission-matrix.md`：角色与资源操作权限
- `acceptance-scenarios.md`：阶段验收和端到端场景
- `implementation-workflow.md`：降低返工和半完成数据的实施流程
- `adr/0001-candidate-is-separate-entity.md`：候选任务模型变更
