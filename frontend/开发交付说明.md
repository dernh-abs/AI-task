# 全意 AI 工作中枢｜开发交付说明

## 交付范围

本交付包包含当前完整前端演示、构建产物、产品资料与两个工作台视角：

- 团队成员视角：`/`
- CEO／任务分配者视角：`/?role=ceo`
- 免启动预览入口：`design-preview.html`（自动进入当前 `dist/` 构建；CEO 视角可追加 `?role=ceo`）

主要功能区域包括工作台、项目空间、任务池、问问 AI 助手、能力库、AI 执行中心及相关任务详情、弹窗与交互状态。

## 本地运行

```bash
pnpm install
pnpm dev
```

默认开发地址通常为 `http://localhost:5173/`。生产构建与预览：

```bash
pnpm build
pnpm preview
```

## 主要代码位置

- `src/AppV2.tsx`：页面结构、路由视图和主要交互逻辑
- `src/workHub.css`：工作中枢整体视觉、组件和响应式样式
- `src/workHubData.ts`：工作台及业务演示数据
- `src/data.ts`：补充演示数据
- `src/store.tsx`：前端状态管理
- `src/main.tsx`：应用入口
- `dist/`：已验证的生产构建产物
- `design-preview.html`：只负责转入当前构建，不再保存独立旧版页面

## 隐私与排除项

- 交付包不得包含个人简历、个人照片或 `resume_visual/` 目录。
- 交付包不得包含 `node_modules/`、缓存、Git 历史或临时文件。
- 打包完成后需复核 ZIP 清单，避免旧版独立预览文件和个人资料混入。

## 开发验收重点

- 分别检查团队成员与 CEO 两个入口，确认内容和操作权限语义不串联。
- 检查工作台统计卡、今日任务、待接收／待分配、会议／聊天任务提取弹窗。
- 检查任务池的我的任务、开放任务、候选任务、已完成任务，以及任务详情中的负责人、交付物、验收人、截止时间、阻塞原因和 AI 执行跳转。
- 检查项目空间卡片、项目总览、项目 AI 协作与能力库发起协作的项目／非项目分流。
- 检查问问 AI 助手的附件、专家、Skill、连接器选择及输入区溢出状态。
- 检查 AI 执行中心的执行中、待确认、已完成卡片和继续交代／版本产物逻辑。
- 建议在常用桌面分辨率和窄屏环境检查文字截断、弹窗滚动、卡片间距与固定输入区。

## 需研发确认

- 当前为前端交互演示，数据与部分操作使用本地状态／浏览器存储模拟，尚未接入正式后端。
- 登录、组织权限、CEO／成员身份识别、消息通知、验收提醒和多人实时协作需结合正式账户与权限服务实现。
- 会议、聊天、文件、项目资产、专家、Skill、连接器及 Agent 执行需要确定真实 API、数据模型和失败重试机制。
- 正式上线前需补充埋点、可访问性、异常／空数据、网络失败及权限不足等完整状态验收。
