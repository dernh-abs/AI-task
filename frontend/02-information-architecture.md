# 全意 AI Task OS｜信息架构 V1.0

## 1. 一级导航

```text
首页
项目
任务
求助
我的
```

V1不将“会议”设置为独立一级导航，会议内容分布在首页、项目详情和任务来源中。

## 2. 全局结构

```text
首页
├── 候选任务
├── 今日可执行
├── 待我确认
├── AI执行状态
├── 项目风险
├── 等待外部提醒
└── 推荐任务

项目
├── 项目列表
└── 项目详情
    ├── 概览
    ├── 阶段
    ├── 当前可执行
    ├── 等待外部
    ├── 决策与会议
    ├── 成员与外部联系人
    ├── 风险与阻塞
    └── 项目贡献

任务
├── 我的任务
├── 我创建的
├── 开放任务池
├── AI推荐
├── AI执行中
├── 等待外部
└── 已完成

求助
├── 发布求助
├── AI初步回答
├── 待我回答
├── 已解决
└── 知识沉淀

我的
├── 我的工作台
├── 我的Agent
├── 贡献积分
├── 成就记录
└── 个人设置
```

## 3. 首页信息优先级

### 第一层：需要立即处理
- 待我确认的候选任务
- 待我验收的AI任务
- 已阻塞任务
- 今日到期任务

### 第二层：当前可执行
- 今日任务
- 进行中任务
- 推荐认领任务
- AI执行中的任务

### 第三层：低打扰提醒
- 临期等待外部
- 项目风险
- AI推荐任务
- 本周贡献

## 4. 项目详情结构
顶部：项目名称、当前阶段、项目目标、项目负责人、总体进度、风险状态。

内容：概览、阶段、成员与外部对象、决策与会议、风险与阻塞、项目贡献。

## 5. 任务详情结构

### 基础信息
标题、项目、阶段、优先级、截止时间、来源、创建人、负责人。

### 执行信息
执行模式、执行者、AI Agent、当前状态、当前步骤、验收人。

### 内容信息
背景、目标、交付物、验收标准、AI建议、风险、依赖。

### 协作信息
评论、求助、决策记录、外部依赖、执行日志。
